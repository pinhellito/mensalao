iPhone / iPad: Arquivos não oferece Safari ou Chrome, ou os botões não funcionam?

Para index.html o iOS costuma abrir só uma pré-visualização fraca; o Safari muitas vezes não aparece no Compartilhar. Tente nesta ordem:

  1. Deslize os ícones na primeira linha do Compartilhar para a esquerda — o Safari pode estar escondido no fim.
  2. Role até o fim da folha → Editar ações… (ou Mais) e ative Safari (e Chrome, se tiver instalado) nas ações sugeridas.
  3. E-mail: envie o index.html para você mesmo. No app Mail, abra o anexo; com o arquivo na tela, toque em Compartilhar de novo — às vezes o Safari só aparece a partir daqui.
  4. App grátis “Documents” (Readdle) na App Store: abra o app → importe o arquivo dos Arquivos → toque no index.html → ele abre num navegador interno onde os botões costumam funcionar.
  5. Abrir por um link (recomendado): no computador, acesse app.netlify.com/drop, arraste uma pasta que contenha só o index.html, e use o endereço https://… .netlify.app no Safari do iPhone como um site normal (sem depender do app Arquivos).

Controle do mensal

Jogos às quintas. Uso no celular: um arquivo index.html — abra no Safari ou Chrome (não só na pré-visualização do app Arquivos no iPhone). Os lançamentos ficam salvos só neste aparelho, na memória do navegador (não “viajam” junto se você mandar outro .html para o telefone). Deixe o arquivo sempre no mesmo lugar (mesma pasta) para o navegador continuar encontrando os dados.

Lembrete do mensal no WhatsApp

O WhatsApp não permite que um site ou arquivo HTML envie mensagem sozinho para uma lista de transmissão. O que dá para fazer (oficial e simples): abrir o app já com o texto pronto; aí você escolhe a lista de transmissão e manda.

Use os marcadores {mes} (mês por extenso), {mes_curto} (05/2026) e {extra} (texto do campo acima).

Se alterar o modelo, use Salvar modelo para ele entrar no backup JSON.
